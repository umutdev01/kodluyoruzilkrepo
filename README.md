# kodluyoruzilkrepo

Bu repo kodluyorum front end eğitimi için oluşturduğum ilk repodur.Bir adet README dosyası ve html.index barındırır

## installation

öncelikle klonlayın https://github.com/umutdev01/kodluyoruzilkrepo.git

```
git clone https://github.com/umutdev01/kodluyoruzilkrepo.git
```

```
cd kodluyoruzilkrepo

```
